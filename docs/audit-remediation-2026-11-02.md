## 根因与上线状态

代码级根因已确认：原默认 DB_SINGLETON_ENABLED=false 时，每次 db() 调用创建新的、未统一追踪关闭的 postgres 连接池。回归测试在修改前复现、修改后通过。现在 Node 进程共用受限连接池；没有提高默认并发数；Worker 分支仍逐调用隔离。

**不能据此宣称线上 Digest 3914836991 已消失。** 生产异常栈和部署身份未获得：本机 Vercel CLI 未登录，无可用部署配置。已新增隐私安全的认证/工作室错误编号与数据库/网络错误分类，便于上线后关联日志；不记录原始 SQL、照片、提示词、凭据或完整异常堆栈。

本次仅本地修改和验证，没有推送、部署、改线上环境变量或生产数据库，不需要数据库迁移。线上原站点不会因本地修改自动更新。

## 复核决策与限制

1. 独立复核发现刷新账户能力会抹掉提交错误：已补先失败再通过的回归测试，并调整为刷新后保留操作错误/验证门槛。
2. 独立复核发现 Back 绕过链接点击警告：新增同 URL 历史保护与浏览器取消后保留照片验证。历史保护可能留下一个同 URL 历史项；跨站完整离开仍由浏览器标准离开提示处理。
3. 本地草稿采用**同一浏览器保留一个、手动替换**，界面事先说明恢复/替换行为。登录交接仍每次独立 token；本地草稿不是跨设备图库。规划文件原“tab-scoped”约束改为此明确的产品取舍，避免关闭单个标签即失去恢复入口。另一标签可以主动替换浏览器草稿，因此多标签并行编辑时应各自及时下载/保存结果；并发保存期间检测指针变更，防止静默覆盖。
4. 7 天是读取有效期，不是后台删除承诺：到期草稿在下次读取或存储操作时清理；浏览器也可能自行清理存储。
5. 真机 iOS/Safari、支付到账、失败退款、2K/4K 和生产服务连续可用性仍应在部署后单独验收。
